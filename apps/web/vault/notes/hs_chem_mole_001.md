## 核心桥梁：物质的量 n

n = m / M = N / N_A = V / V_m = c · V(溶液)

其中 N_A = 6.02×10²³ /mol，标准状况下 V_m = 22.4 L/mol。

## 常用换算

| 已知 | 求 n 的公式 |
|---|---|
| 质量 m (g) | n = m / M |
| 微粒数 N | n = N / N_A |
| 气体体积 V（标况） | n = V / 22.4 |
| 溶液浓度 c、体积 V | n = c·V |

## 例题

标准状况下 4.48 L CO₂ 的质量是多少？

n = 4.48/22.4 = 0.2 mol，m = 0.2×44 = 8.8 g。

## 阿伏加德罗常数判断题（高频）

1. 标况下非气体（水、SO₃、CCl₄）不能用 22.4。
2. 溶液中离子数要考虑水解。
3. 转移电子数要看反应中元素化合价变化。

## 易错点

1. 气体体积不说明"标准状况"就用 22.4。
2. 摩尔质量单位写成 g 而非 g/mol。
3. 浓度计算忘记溶液体积单位换算（mL→L）。
