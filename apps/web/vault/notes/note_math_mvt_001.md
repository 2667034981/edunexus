## 这是什么

三大中值定理把"函数值"和"导数值"连起来，是证明题的主力工具。

- 罗尔定理：f 在 [a,b] 连续、(a,b) 可导、f(a)=f(b)，则存在 ξ 使 f'(ξ)=0。
- 拉格朗日中值定理：f(b) - f(a) = f'(ξ)(b - a)。
- 柯西中值定理：两个函数之比的版本。

## 怎么用

1. 看到"存在 ξ 使 f'(ξ) = ..." → 想罗尔或拉格朗日。
2. 判断单调性：f'(x) > 0 递增，f'(x) < 0 递减。
3. 求极值：先找 f'(x)=0 的驻点，再看两侧符号变化。

## 例题

证明当 x > 0 时，ln(1 + x) < x。

令 f(x) = x - ln(1 + x)，f(0) = 0，f'(x) = 1 - 1/(1+x) = x/(1+x) > 0（x>0），所以 f 严格递增，f(x) > f(0) = 0，得证。

## 易错点

1. 用中值定理前不验证三个条件（连续、可导、端点值）。
2. 极值点和驻点混为一谈：驻点不一定是极值点。
3. 忽略定义域，尤其是 ln、根号这类。
