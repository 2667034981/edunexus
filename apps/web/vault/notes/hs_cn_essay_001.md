## 基本结构：五段三分

1. 开头：引材料 + 亮观点（100 字内）。
2. 分论点一 + 论据 + 分析。
3. 分论点二 + 论据 + 分析。
4. 分论点三 + 论据 + 分析（或让步段）。
5. 结尾：回扣观点 + 升华（150 字内）。

## 分论点怎么拆

- 并列式：是什么、为什么、怎么办。
- 递进式：个人 → 社会 → 时代。
- 对比式：正面 → 反面 → 辩证。

## 三种论证方法

| 方法 | 说明 | 例 |
|---|---|---|
| 举例论证 | 事实论据 | 苏轼、张桂梅、航天团队 |
| 道理论证 | 引用名言、原理 | "苟日新，日日新" |
| 对比论证 | 正反对照 | 空谈者 vs 实干者 |

## 素材使用要点

不要堆砌，每个论据后必须有 **2—3 句分析**，把"事例"和"观点"连起来。

公式：**观点 + 事例 + 分析 + 小结**。

## 常见失分

1. 只有事例没有分析（"以叙代议"）。
2. 三个分论点重复，没有层次。
3. 结尾喊口号，与观点脱节。
