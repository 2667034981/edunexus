## 这是什么

函数是高中数学的骨架：给定非空数集 A，对 A 中每个 x，按某种对应关系 f，都有唯一确定的 y 与之对应。

三要素：**定义域、对应关系、值域**。判断两个函数是否相同，只看定义域和对应关系。

## 必背结论

- 单调性：任取 x₁ < x₂，若 f(x₁) < f(x₂) 则递增；判断可用作差法或求导。
- 奇偶性：f(−x) = −f(x) 为奇函数（图象关于原点对称）；f(−x) = f(x) 为偶函数（关于 y 轴对称）。
- 定义域优先：做题第一步永远是求定义域，尤其是分式、根式、对数。

## 四类基本初等函数

| 类型 | 形式 | 关键性质 |
|---|---|---|
| 二次函数 | y = ax² + bx + c | 对称轴 x = −b/2a，最值在顶点 |
| 指数函数 | y = aˣ (a>0, a≠1) | 过 (0,1)，a>1 递增，0<a<1 递减 |
| 对数函数 | y = logₐx | 过 (1,0)，与指数函数互为反函数 |
| 幂函数 | y = xᵃ | 看指数正负判断单调性 |

## 例题

已知 f(x) = x² − 2ax + 3 在 [1, 2] 上单调递增，求 a 的取值范围。

对称轴 x = a。开口向上，递增区间是 [a, +∞)，要覆盖 [1,2]，需 a ≤ 1。

## 易错点

1. 忘记先求定义域，直接做单调性判断。
2. 奇偶性判断忘了"定义域必须关于原点对称"这一前提。
3. 分段函数求值代错分支。
