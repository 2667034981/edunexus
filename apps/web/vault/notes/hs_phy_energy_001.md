## 功与功率

- 功：W = F·s·cosθ。
- 功率：P = W/t = F·v·cosθ（瞬时功率用瞬时速度）。

## 动能定理

W合 = ΔEk = ½mv₂² − ½mv₁²

**优点**：不关心过程细节，只看初末状态，适合变力、曲线运动。

## 机械能守恒

条件：只有重力或弹力做功。

Ek₁ + Ep₁ = Ek₂ + Ep₂

## 功能关系速查

| 力做功 | 对应能量变化 |
|---|---|
| 合外力做功 | 动能变化 |
| 重力做功 | 重力势能变化（负相关） |
| 弹力做功 | 弹性势能变化 |
| 除重力弹力外其他力做功 | 机械能变化 |
| 摩擦生热 | Q = f·s相对 |

## 例题

物体从高 h 的光滑斜面滑下，求底端速度。

机械能守恒：mgh = ½mv²，得 v = √(2gh)。

## 易错点

1. 有摩擦时仍用机械能守恒。
2. 摩擦生热用对地位移而非相对位移。
3. 动能定理漏掉某个力做的功。
