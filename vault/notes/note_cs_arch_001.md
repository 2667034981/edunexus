## 这是什么

冯·诺依曼结构：运算器、控制器、存储器、输入、输出，程序和数据都存在内存里，按地址顺序执行。

## 存储层次（从快到慢、从小到贵）

寄存器 → 一级缓存 → 二级缓存 → 内存 → 固态硬盘 → 机械硬盘

设计思想：用少量高速存储 + 大量低速存储，靠局部性原理（时间局部性、空间局部性）达到接近高速的性能。

## 关键指标

- CPU 主频、核心数、字长
- 内存容量与带宽
- 存储单位：1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB

## 易错点

1. 把 1 KB 当作 1000 B（存储领域通常按 1024）。
2. 认为缓存越大程序一定越快（还要看命中率）。
3. 混淆 32 位/64 位系统对内存寻址的限制。
